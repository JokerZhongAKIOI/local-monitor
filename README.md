# Local Monitor

可扩展的本地用户在线状态监控面板。Python 3.10+，无第三方运行依赖。

## 运行

```sh
python server.py
# 打开 http://127.0.0.1:8000
```

开发预览可使用 `python server.py --host 0.0.0.0 --port 8000`。**默认仅绑定回环地址；本产品目前没有面板访问认证，切勿暴露到公网或不可信局域网。** 任何能访问面板的人均可查看 IP、管理监控。

首次打开显示明确标注的静态演示数据，点击「退出演示」查看真实监控。演示与真实数据隔离，演示记录不能调用真实站点。

## 功能

- 两个预置站点：`http://10.177.41.90` 与 `https://www.goj.wiki`
- 登录接入、多个目标用户、在线/IP 状态、15 秒轮询
- 暂停/恢复、删除、搜索、状态筛选
- 状态变化与错误日志、JSON 日志导出
- SQLite 本地持久化，仅保留最近 500 条活动记录
- 密码不落盘，Cookie 会话仅存在内存，重启需移除监控后重新登录

## GOJ 个人活动会话模式

在添加监控时选择 GOJ，仅需输入自己的账号和密码，无需填写目标用户名或接口。新增适配器 `goj.py`：

- POST 表单 `/login?redirect=%2F`，使用 `uname` / `password`，`tfa` / `authnChallenge` 留空。
- 允许同源登录跳转，禁止跨源跳转及 307/308 密码重发；通过读取会话页面验证登录结果，不把 302 直接当成功。
- GET `/home/security`，解析当前会话的 IP 和最后活动时间。未返回 IP 则显示空值。
- 状态为「会话有效」，不是「实时在线」。仅展示本监控客户端自己的当前会话，不会查询其他用户，也不会展示账号其他设备的会话。轮询可能更新该会话的活动时间。
- 若网站要求 `/user/sudo` 再次身份验证、验证码、双重验证或改变 HTML 结构，会报错；目前不自动提交 sudo 密码，也不支持这些额外验证流程。
- 按用户提供的脱敏 HTML 和登录字段编写，已做离线测试，**尚未用真实账号完成网站集成验证**。
- 完整项目运行需要保留 `goj.py` 与 `server.py` 同级。

以下 JSON 接口说明适用于内网站点及通用模式，不适用于上述 GOJ 个人会话模式。

## 通用 JSON 接入前提（重要）

**通用模式尚未适配内网站点实际协议；GOJ 使用上方专用适配器，仍待真实集成验证。** 不能仅凭用户名和密码推导其他用户的 IP。必须有管理权限或用户明确授权，且站点须提供可读取在线 IP 的接口。普通个人账号通常无此权限。用户在页面中自行填写凭据，不要把密码发到聊天、写进源码或提交 Git。

通用模式实现的是可配置 JSON + Cookie 协议适配器，不是通用网页登录抓取器。需要从站点管理员处获取：

1. 登录路径（同站点绝对路径，例如 `/实际登录接口`）；后端 POST JSON，可配置用户名及密码字段名。
2. 登录成功响应为 `{"success": true}`，且设置有效的会话 Cookie。
3. 状态路径；后端 GET，追加 `username=目标用户名`，携带登录 Cookie。
4. 状态响应示例：`{"online": true, "ip": "203.0.113.5"}`；离线为 `{"online": false}`。未提供 IP 时显示 `—`，不会猜测。

这里的路径是协议说明，并非已确认可用的站点路径。若网站使用表单、CSRF、验证码、SSO 或 Bearer token，需要在获得实际接口规范后编写对应适配器。所有重定向都会拒绝，避免登录凭据被转发到其他站点。接口限于选定站点，响应限 1MB，单请求超时 8 秒。轮询串行，站点响应慢或监控很多时实际检查间隔会增加。

内网站点必须在能访问 `10.177.41.90` 的机器上运行。远程开发预览无法代表用户本机网络，也不能验证内网连通性。内网站点使用明文 HTTP，仅应在可信网络使用。

## 数据与隐私

- 默认数据库：`data/monitor.db`，可通过 `MONITOR_DB` 环境变量覆盖。
- 数据目录已加入 `.gitignore`；保存目标用户名、当前 IP 与变化日志，不保存登录账号、密码或 Cookie。
- 删除监控会清除内存会话，历史日志仍保留。需要清除全部记录时，停止服务并删除数据库。
- 不提供 IP 定位、绕过认证、探测隐藏接口或未授权跟踪。
- 面板轮询本地服务每 5 秒一次；后端轮询远端站点每轮完成后等待 15 秒。手动刷新触发下一轮。

## 验证

```sh
python -m unittest discover -s tests -v
node --check static/app.js
```

测试覆盖站点路径限制、在线/离线、无效 IP、严格布尔状态、日志去重、暂停状态保护。尚无真实站点集成测试。

## 文件结构

- `server.py`：标准库 HTTP 服务、JSON 接入、SQLite、轮询
- `static/`：中文响应式界面
- `tests/`：后端单元测试

后续可扩展站点专用适配器、通知、历史曲线及面板访问认证。

## Windows / IDLE 常见问题

请下载并解压**完整项目**，不要只把 `server.py` 复制为 `test.py`。需要以下目录结构：

```text
local-monitor/
  server.py
  goj.py
  start.bat
  static/
    index.html
    app.js
    style.css
```

Windows 可双击 `start.bat`（需要 Python Launcher），或在项目文件夹的终端运行 `python server.py`。也可在 IDLE 打开 `server.py` 后按 F5。看到运行地址后，在浏览器中打开 `http://127.0.0.1:8000`。

若将 Python 文件改名为 `test.py`，`static` 文件夹仍需与它同级。`FileNotFoundError: ...static/index.html` 表示前端文件未完整解压到正确位置，与 Python 3.12 版本无关。新版会在启动前检查这些文件，并给出明确提示。
