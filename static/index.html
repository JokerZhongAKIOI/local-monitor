添加用户监控

使用有权限的账号连接站点。密码仅用于本次登录，不会保存。

GOJ 个人会话模式：自动使用 uname / password 表单登录并读取 /home/security。仅展示登录账号当前会话的 IP 与最后活动时间，不代表实时在线，也不能查询其他用户。监控客户端会创建自己的会话，其活动时间可能因轮询而更新。若需要二次身份确认，可勾选下方授权，用本次密码完成一次验证；密码不保存，未来验证过期时需重新连接。浏览器中的验证不会同步给本程序。
接口配置 需与站点管理员确认
登录：POST JSON，返回 {"success": true} 并设置会话 Cookie。状态：GET，附带 username 参数，返回 {"online": true, "ip": "…"}。
仅监控你拥有管理权限或已获明确授权的用户。内网站点使用 HTTP，登录凭据无传输加密，请仅在可信网络使用。
